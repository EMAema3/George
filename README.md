# Casa Playa — Aruba residences

Direct-booking website for a portfolio of Oranjestad vacation residences.
Live with **Casa Playa 204**; built to scale to six properties.

- **`ARCHITECTURE.md`** — how the platform is structured and how to add properties
- **`SETUP.md`** — what to configure (Stripe, Netlify, GitHub, data to update before launch)

```bash
npm install
npm run dev       # local dev at localhost:4321
npm run build     # static build to dist/
```

5 languages (en/es/nl/pt/de) · 2-click Stripe booking · itemised Aruba levies ·
VacationRental schema · the tile-and-arch design system from the building itself.
